## 🔴 버그로 보이는 것 (UI 개선 이전에 수정 필요)

디자인이 아니라 **깨져 보이는** 항목이라 최우선.

1. **보스 체력바가 미완성/깨져 보임** — [04-boss.png](04-boss.png), [08-continue.png](08-continue.png)
   상단 중앙에 하트 아이콘 + 얇은 빨간 막대가 떠 있으나 채움(fill) 상태·배경 트랙·테두리·라벨("BOSS")·퍼센트가 없어 "체력바"로 읽히지 않는다. → `BossHealthBar` 렌더링 점검.

2. **컨티뉴 화면의 빨간 격자 아티팩트** — [08-continue.png](08-continue.png)
   "GAME OVER" 글자 왼쪽에 빨간 그물망 사각형 격자가 텍스트와 겹쳐 그려진다. 렌더 글리치(폰트/이미지 비정상 출력 또는 z-order 문제).

3. **게임오버 배경 정렬 깨짐** — [06-gameover.png](06-gameover.png)
   `gameover` 배경이 좌상단 기준(`this.x/this.y` undefined 추정)으로 그려져 화면 위쪽만 덮고 상하단에 검은 레터박스가 남는다. 배경을 화면 중앙·풀스크린으로 정렬 필요.

4. **게임클리어 타이틀 "ENDER"** — [07-gameclear.png](07-gameclear.png)
   "THE END" / "ENDING" 의도로 보이나 "ENDER"로 잘려/오타로 출력된다. 의도된 워드마크가 아니면 수정.

5. **에셋 로드 실패** (README 메모)
   `background2_4`, `background4_*`, `background5_*` 콘솔 에러 — Preloader 키/파일 경로 점검.

## 🟠 시각적 위계 & HUD 일관성 (가장 큰 디자인 이슈)

HUD가 **네 모서리에 제각각** 흩어져 있고 스타일·크기·등장 조건이 통일돼 있지 않다.

- 목숨/포인트 → 좌상단
- 타임 → 우상단
- 효과 스탯(이동속도/발사속도/알크기/데미지) → 우하단, **아주 작고 저대비**
- 볼륨 슬라이더 → 좌하단 (보스전에서만 보임? 일관성 의문)

개선 방향:

- **HUD를 하나의 디자인 언어로 통일** — 공통 배경 캡슐/패널(반투명 어두운 배경 + 일정 radius), 동일 폰트 크기 단계, 동일 아이콘 셋. 현재 픽셀 폰트 크기·아이콘 스타일이 화면마다 달라 보인다.
- **우하단 효과 스탯 가독성** ([02-first-stage.png](02-first-stage.png), [03-second-stage.png](03-second-stage.png), [04-boss.png](04-boss.png)): 화려한 배경 위 작은 저대비 텍스트라 거의 안 읽힌다. 반투명 어두운 배경 패널 또는 아웃라인/그림자로 대비 4.5:1 이상 확보.
- **타임 표시**: `TIME: 00:00`이 카운트다운인지 경과인지 모호. 보스전 `00:00`이면 멈춘 것처럼 보인다.
- **볼륨 슬라이더 위치**: 인게임 좌하단 상시 노출은 산만하다. 메뉴/일시정지로 이동하거나 최소한 전 씬에서 일관되게.

## 🟡 메뉴 화면 — [01-menu.png](01-menu.png)

- **메뉴 버튼 대비 부족**: "게임 시작 / 게임 설명" 흰 텍스트가 밝은 하늘 배경과 겹쳐 거의 안 보인다. 버튼 배경(반투명 패널·테두리) 또는 텍스트 아웃라인/그림자 추가. 메뉴는 첫인상이라 최우선.
- **선택 커서(노란 화살표)가 모호**: 어떤 항목이 선택됐는지 즉각 안 읽힌다. 선택 항목 자체를 강조(스케일/색/하이라이트 배경)하는 편이 명확.
- **구성 균형**: 큰 꼬꼬(우), 보스 소(좌상), GRUW 크레딧(우하), 로고(상중) — 요소가 많아 시선이 분산된다. 로고+메뉴를 시각적 중심축으로 또렷하게 묶기.
- **선택/호버 피드백**: 마우스/키보드 양쪽에서 현재 선택 상태가 애니메이션으로 드러나면 게임다운 맛이 산다.

## 🟡 게임오버 / 컨티뉴 / 클리어 화면

- **게임오버 텍스트가 너무 작고 약함** — [06-gameover.png](06-gameover.png): "GAME OVER"가 화면 대비 작고 평범하다. 엔딩 임팩트 부족. 크게 키우고 등장 모션(페이드/스케일) 추가.
- **컨티뉴 카운트다운 "8"** — [08-continue.png](08-continue.png): 숫자만 덜렁 있어 의미 전달이 약하다. 원형 타이머 링이나 줄어드는 바를 곁들이면 "시간 안에 누르라"는 메시지가 명확해진다.
- **클리어 스토리 텍스트 가독성** — [07-gameclear.png](07-gameclear.png): 작은 픽셀 폰트 + 배경 위 본문이라 줄간격/대비가 빠듯하다. 본문 뒤 반투명 패널 + 줄간격 1.5 확보.

## 🟢 잘 된 점

- 픽셀 아트 톤이 일관되고 캐릭터(꼬꼬·돼지·고양이·골드피그)가 귀엽고 식별성이 좋다.
- 스테이지별 배경 차별화(평원→산→동굴/보스)로 진행감이 느껴진다.
- 효과를 수치로 노출(이동속도/발사속도/알크기/데미지)하는 정보 설계 자체는 좋다 — **가독성만** 올리면 된다.
- i18n 언어 토글이 메뉴에 노출돼 있다.
